Build the course fingerprint like the chart fingerprint: `createCourseFingerprintDocument` returns a canonical document that carries its version (`v: 'bmcourse0'`), and `computeCourseFingerprint` hashes its RFC 8785 text. A NONSTOP course now lists one connection per seam, reading a seam the course does not name as `fade` as the stitcher does, so courses that stitch alike share a key. Every course fingerprint changes.
