Once a RANDOM MIX run is over, played through or given up, and its result left, the select screen offers to save it: the dialog names the course by the date and time the run ended (editable), lists every stage drawn, and shows the settings the run started with, read-only. Saving keeps the course as one of your own, which the next draw no longer replaces.

A NONSTOP RANDOM MIX now takes 1-99 stages, as an EXPERT one does, and a RANDOM MIX of any counted length is kept as its folder's newest course (only an endless run is not); your courses now keep every stage. Exporting your courses as `.lr2crs` writes each course's first five stages, the ones LR2 plays. A course result with more stages than the skin lists scrolls its stage list so every stage is shown.
