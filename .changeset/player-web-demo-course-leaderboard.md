Submit course runs to the Leaderboard: with "Submit to Leaderboard" on, a finished course (cleared or failed) is sent as one run when its result shows, and its course rank goes to the status line. The course play log now records each unreached stage's chart fingerprint (of the chart as the course plays it), so a failed run is ranked on the same course, and its unreached stages' facts are read from that chart too.
