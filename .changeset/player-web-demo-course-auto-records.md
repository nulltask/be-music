An auto-played course run no longer becomes the course's best record: a run with any stage (or a NONSTOP run's stitched play) played with AUTO keeps no record, as an auto play keeps none for a chart. As LR2 does, a course played with AUTO also skips the result of every stage the course goes on after; the last stage's result and the course result still show.
