A search that starts with `?` is a chart filter expression, the SQL `WHERE` clause beatoraja random courses use: the list shows the charts it selects (from every folder at the root), in its own `ORDER BY` order when it has one. Charts are read through the new `Library.chartFilterRecord`, else `libraryChartFilterRecord`. An expression that does not parse filters nothing, and `browseSearchError` says why. New `parseBrowseSearch`, `browseSearchError`, `libraryChartFilterRecord` and `filterEntriesByChartQuery`.
