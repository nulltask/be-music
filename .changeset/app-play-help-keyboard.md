Help gains a Keyboard tab that draws each screen's keys (select, decide, play, result and every screen) on a keyboard, from the player's own lane keys, START / SELECT and operation keys, on LR2's or beatoraja's key map. Numbers mark the white and black keys, ◎ the turntable, ST / SL START / SELECT and ● an operation's key; pointing at a line of the list beside it lights that operation's keys.
