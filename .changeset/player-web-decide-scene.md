Add `createDecideScene(kit, options)`, which makes the decide screen of every family. It draws the chart's `#RANDOM` / `#SWITCH` branches once (`random`, `Math.random` by default) and exposes them as `scene.resolved` for the play's `preResolved`, so the screen's graphs show the branches the play plays. It times the screen from the skin (LR2's `#STARTINPUT` and `#FADEOUT`, beatoraja's `input`, `scene` and `fadeout`, a be-music skin's `decide.durationMs`), continues on Enter, Space or a click once input is open, backs out on Escape, and plays the theme's decide jingle (`sounds.decideBGM`) through the audio service. `progress` reports how far the play behind the screen has loaded, and fills a skin's loading bar over the auto advance when the host reports none. An auto-repeated key no longer continues or backs out, so a key held down from the select screen does not skip the screen, and a key typed into a text field is the field's.

Migration:

- `new DefaultPixiDecideView({ beMusicSkin, beMusicEffects, beMusicSkinSettings, playOptions, onContinue, onCancel })`, then `view.mount(host, { song, collection })` → `createDecideScene({ family: 'built-in', skin: beMusicSkin, effects: beMusicEffects, settings: beMusicSkinSettings }, { chart: song, playOptions, source: resolveSongSource(collection, song), sounds, audio, on: { continue: onContinue, cancel: onCancel } })`, then `host.setScene(scene)`, where `audio` is the host's `createAudioService()` and `sounds` the theme's `SystemSoundSet` (`{}` to play no jingle).
- `new PixiDecideView({ skin, onContinue, onCancel })` → `createDecideScene({ family: 'lr2', skin }, { … })` as above. A host that showed it without a skin shows the built-in decide screen instead.
- `new PixiBeatorajaDecideScene({ skin, textures, fonts, skinConfig, song, chart, chartImages, bgmBytes, skinAudio, autoAdvanceMs, getLoadingProgress, onContinue, onCancel })` → `createDecideScene({ family: 'beatoraja', kit }, { chart: song, source, sounds: { decideBGM: { bytes: bgmBytes } }, progress: getLoadingProgress, audio, on: { continue: onContinue, cancel: onCancel } })`, where `kit` is `loadBeatorajaSceneKit`'s and `audio` has the theme's files set (`audio.setTheme({ files })`) for the skin's Lua sounds. The scene loads `#STAGEFILE`, `#BACKBMP` and `#BANNER` from `source` and draws its graphs from its own draw of the chart; `autoAdvanceMs` has no counterpart, as the screen moves on after the skin's `scene`.
- `view.durationMs` → gone: the scene moves on by itself and calls `on.continue`.
- `view.setBeMusicSkinSettings(settings)` → `scene.updateKit({ ...kit, settings })`.
