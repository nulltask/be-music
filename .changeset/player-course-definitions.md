Add `@be-music/player/course`, one course model for every source, so every host and the Leaderboard read courses by the same rules:

- `CourseDefinition` for LR2 `.lr2crs` files, beatoraja `course/*.json` files and the `course` / legacy `grade` lists of difficulty-table headers, with their parsers (`parseLR2CourseFile`, `parseBeatorajaCourseFile`, `parseTableHeaderCourses`, `parseBeatorajaRandomCourseData`, and `parseBeatorajaCommandFolderFile` for the random courses of beatoraja's `folder/default.json`), beatoraja's constraint and trophy normalisation, and `resolveCourseStages` to match each stage to a local chart by SHA-256 or MD5.
- LR2's reading: every `.lr2crs` course is read as its first five stages (`LR2_MAX_PLAYED_STAGES`), as LR2 plays at most five stages of any course although its course bar lists up to ten, and `countLR2UnplayedStages` tells a host how many were cut. An LR2 GRADE course reads as `grade` with `gauge_lr2`, which allows no lane option, as LR2 turns both sides' lane options off when a GRADE course starts; a difficulty table's legacy grade keeps jbmstable-parser's `grade_mirror`. A table course stage without a title is named `course N`, as beatoraja's `CourseData.validate` names it.
- Difficulty-table URLs: `resolveTableHeaderURL` finds the `<meta name="bmstable">` header link in a table page, and `fetchTableHeaderCourses` follows a page URL (or reads a header JSON URL directly) through an injected `fetchText` and returns the table's label and courses, without fetching the `data_url` song list.
- Random courses: `parseCourseSongFilter` / `evaluateCourseSongFilter` read the SQL `WHERE` subset beatoraja's random-course stages are written in (comparisons, `AND` / `OR` / `NOT`, `IN`, `LIKE`, `BETWEEN`, `IS NULL`, arithmetic) against a neutral `CourseSongRecord` with SQLite's comparison rules, failing closed on anything else, and `drawRandomCourse` draws one chart per stage with an injected `random` (beatoraja's `distinct` rule included) into a fixed `CourseDefinition`, unreleased like beatoraja's. Random-course stages keep their `title`.
