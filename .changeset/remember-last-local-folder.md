Remember the folders the player opens or drops, on browsers that can keep folder access, and load them again on the next visit. Options → Library & records lists them under Folders to load, where a folder is added, changed or removed for the next visit, and opening or dropping another folder adds it to the list. A folder whose access the browser asks for again shows a Reconnect button; a saved folder the browser no longer answers for is taken off the list with a note saying so, and the rest of the library loads as usual. A folder dropped where access cannot be kept is listed for the current visit, and a folder drop opens the Library root with the new folder selected.
