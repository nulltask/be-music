Add `@be-music/fingerprint-c`, a portable C99 port of the Be-Music Fingerprint (library, CLI and bare WebAssembly module). This first release holds the numeric core, matched against the TypeScript implementation by generated test vectors: exact rationals and snapping, JavaScript's decimal/double conversions done with integer arithmetic, and SHA-256.
