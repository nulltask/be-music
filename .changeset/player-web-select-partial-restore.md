On the built-in and LR2 select screens, a saved place whose folder is gone (a library rebuilt by a drop or a NONSTOP run) is restored as far as its folders are still found: at the root, on the cursor saved there. It used to restore nothing, leaving the screen where it was, or, for a new library, opening its one chart folder. A library with no saved place still opens its one chart folder.
