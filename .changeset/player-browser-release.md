PRACTICE bar auditions and loops, RANDOM MIX conditions, a BGA camera, one README dialog, and estimated difficulties.

- Add `AudioService.preview.playWindow(target, { startSeconds, endSeconds })` (`ChartPreviewEngine.playWindow`), which sounds one stretch of a chart at once as AUTO PLAY would play it, cutting the previous one short, for auditioning a bar. `createPlayScene` takes `practiceRange`, the chart milliseconds a PRACTICE play loops.
- A PRACTICE bar's audition (`AudioService.preview.playWindow`) now also sounds what started before the bar and still rings at its bar line, such as a long BGM sample or a long note's keysound, from where it is there, as the loop play already does when it seeks to its start. Under BMS's monophonic WAV playback only each slot's last sample before the bar carries over.
- A PRACTICE play now fades in as it starts and crossfades each time its loop goes back to the start: what still rings at the end fades out over half a second while the next round fades in, instead of the sound cutting off. `createWebAudioSession` takes `seekCrossfadeSeconds` for this.
- Add `createRandomMixCandidate` and `resolveRandomMixBPM` to `@be-music/player-browser/collection`, which read a library chart for a RANDOM MIX without hashing its file, and `CourseMaker.keepRandomMix`, `randomMixConditions`, `setRandomMixConditions`, `setRandomMixSettings` and `setDefaultConnection`, which keep a draw made elsewhere, the RANDOM MIX dialog's conditions, the RANDOM MIX settings and the default NONSTOP connection.
- `createRandomMixCandidate` reads a chart's difficulty as the library lists it (`resolveLibraryChartDifficulty`): its own `#DIFFICULTY` as `difficulty`, an estimate from its names or note count as `estimatedDifficulty`.
- The select screen shows a chart's README in one dialog for every skin family (`<be-music-readme-dialog>` of `@be-music/player-ui`), replacing the canvas overlay of the LR2, beatoraja and built-in skins. Web and mail addresses in the README open in a new tab, and the text is decoded as a chart's own text is (`decodeBMSText`), so a UTF-8 README without a BOM and a UTF-16 one no longer show garbled, and Shift_JIS ones read as before. Synesthesia and Plain draw a small README button at the top right of the focused chart's card, and Native's Readme button is disabled on a chart without one. While the dialog is open, Escape closes it as Enter and Backspace do.
- Add `PlayScene.setBGACamera({ stream, mirror })`, which shows a camera `MediaStream` in the BGA frame in place of the chart's BGA on every play screen: the built-in skins, LR2 skins and beatoraja skins, and a Be-Music Skin that composites the BGA itself. The picture is fitted whole on black, can be mirrored, and the chart's BGA comes back on the next frame after `setBGACamera(undefined)`.
- A chart without `#DIFFICULTY` gets the difficulty its names, else its note count, suggest in the beatoraja select rows' level colour, the beatoraja chart facts and random course filters, as beatoraja's song database fills it in; the built-in skins mark it with `?` (names) or `??` (note count).
- Touch lanes now name their input source (one per lane's touch zone) on the commands they send, so replays record it and a back-spin scratch tapped again on the same zone ends as before; each lane's touch release is sent on its own. Replay playback passes the replay's input-source table to the engine.
