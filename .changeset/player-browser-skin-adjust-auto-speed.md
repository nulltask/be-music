LR2's and beatoraja's number keys in a play. On LR2's key map, a number key held with an arrow moves the play skin (1), scales it (2) or raises and lowers the 1P / 2P lanes' LIFT (6 / 7); the play starts with the host's `skinAdjust` and reports changes through `PlaySceneEvents.skinAdjust`. On beatoraja's key map, an AUTO play runs ×0.25 / ×0.5 / ×2 / ×3 while 1 / 2 / 3 / 4 is held, within the web player's tempo range.
