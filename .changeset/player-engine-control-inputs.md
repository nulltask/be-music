Space is now a default key of the 1P turntable, its second key with Left Ctrl (Option on macOS terminals), as in LR2's default key config. A new `control-input` command records the control buttons that are not lanes (START / SELECT) in the replay as `play.controlInputs`, with their physical keys; like `code`, it is diagnostic only.
