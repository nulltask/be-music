Add `@be-music/player-ui-vue`, typed Vue wrappers for the `@be-music/player-ui` Web Components that forward object properties, typed emits and element refs and register the elements before client mount, among them the playfield components (`BeMusicBGA`, `BeMusicLanes`, `BeMusicNotes`, `BeMusicLaneCovers`, `BeMusicJudgeLine`, `BeMusicBombs`, `BeMusicJudgmentDisplay`, `BeMusicPlayfield`) and the preview components (`BeMusicPlaybackControls`, `BeMusicPreviewHUD`, `BeMusicPreviewSelect` with `images` and `courses`, `BeMusicPreviewStart`).
