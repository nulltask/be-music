Add `createResultScene(kit, options)`, which makes the result screen of every family from a `PlayResult`. It plays the result's jingle from the theme's sounds through the audio service (the verdict's jingle, else the generic one; the course jingles for a course run) and stops it as the screen leaves. It steps the screen as LR2's result timers do: Enter, Space or a click skip the graphs, then show the record update, then continue, and Escape continues at any time; a beatoraja skin leaves on the first press, with Escape held until its `input` has passed. Once input is open, R plays the chart again (`on.retry`) when the run offers a quick retry, a single play or a NONSTOP run (`run`). `playChart` gives a skin's BPM graph, note kinds and `#TOTAL` the chart as played (`PlayScene.resolved`), and the scene loads the chart's images from `source`.

Migration:

- `new DefaultPixiResultView({ beMusicSkin, beMusicEffects, beMusicSkinSettings, collection, clearBgm, failBgm, resultBgm, onContinue })`, then `view.mount(host, result)` → `createResultScene({ family: 'built-in', skin: beMusicSkin, effects: beMusicEffects, settings: beMusicSkinSettings }, { result, run, source: resolveSongSource(collection, result.song), sounds, audio, on: { continue: onContinue, retry } })`, then `host.setScene(scene)`, where `audio` is the host's `createAudioService()`, `sounds` the theme's `SystemSoundSet` (its `clear`, `fail`, `result`, `courseClear` and `courseFail` slots) and `run` which play the result is of (`'single'`, `'stage'`, `'course'` or `'nonstop'`) when `result.run` does not say.
- `new PixiResultView({ skin, … })` → `createResultScene({ family: 'lr2', skin }, { … })` as above; the skin is the theme's result skin, or its course-result skin for a course run. A host that showed it without a skin shows the built-in result screen instead.
- `new PixiBeatorajaResultScene({ skin, textures, fonts, skinConfig, song, chart, summary, maxCombo, scoreHistory, gaugeHistory, timingHistory, chartImages, bgmBytes, skinAudio, onContinue })` → `createResultScene({ family: 'beatoraja', kit }, { result, run, source, playChart: chart, sounds, audio, on: { continue: onContinue, retry } })`, where `kit` is `loadBeatorajaSceneKit`'s (the course-result entry for a course run), `result` the `PlayResult` of `createPlayScene`'s `on.finish` (it carries the summary, max combo, histories and timings), `sounds` the theme's `SystemSoundSet` (`systemSoundSetFromBeatoraja` of `@be-music/scene-model`; the screen picks the jingle, so `bgmBytes` has no counterpart), and `audio` has the theme's files set (`audio.setTheme({ files })`) for the skin's Lua sounds.
- `view.setBeMusicSkinSettings(settings)` → `scene.updateKit({ ...kit, settings })`.
