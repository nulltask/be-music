Play EXPERT and GRADE courses by one set of rules:

- `PlayerOptions.course` runs a chart as one stage of a course: on the ruleset's course gauge (LR2's grade and course gauges by course kind; beatoraja's class gauges `CLASS` / `EXCLASS` / `EXHARDCLASS` per gauge set for beatoraja and IIDX), from the gauge value and course-wide combo the previous stage left, and with the course's `no_good` / `no_great` judge constraint. The play log records `play.course` and the result reports the course combo, so a stage log replays and re-simulates on its own.
- `CourseRun` (`@be-music/player/course`) is one run of an EXPERT or GRADE course: it plans each stage (its chart with the course's long-note constraint, `PlayerOptions.course` with the state the previous stage left, the hi-speed lock), records the stage play logs, ends the run on a failed or last stage, adds up the play time and builds the course play log. A stage given up with ESC fails the run whatever its gauge, as LR2 records it, and `resolveGivenUpPlaySeconds` gives its play time. Its stage entries are the host's own (anything with a `chart` and a `chartPath`).
- The stage rules: `resolveCourseStagePlaySettings` gives the settings a stage plays with in place of the player's picks (the lane options the course allows, then an LR2 GRADE course's resets), built from `resolveCourseStageSettings`, `resolveCourseLaneOptions` (`CourseLaneOption`, `CourseLaneOptions`), `isCourseHiSpeedLocked`, `isLR2GradeCourse` and `resolveLR2GradeCoursePlaySettings` (`LR2GradeResetSettings`); `applyCourseLongNoteConstraint` applies a course's `ln` / `cn` / `hcn` constraint to a stage chart, for a host and the Leaderboard alike.
- `resolveCourseStageStartGauge` (`@be-music/player/playlog`) gives the course gauge a stage starts on (its ruleset id such as `GRADE` / `COURSE-EASY` / `CLASS`, range and border) and the value carried in, before the engine runs, so a host can show it from the stage's READY phase. `resolveChartRulesetFacts` (`@be-music/player`, `@be-music/player/playlog`) gives the ruleset facts of a chart a host has not played (`#RANDOM` takes its first branch), so a course result can count the notes of the stages the run never reached.
