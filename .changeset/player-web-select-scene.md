Add `createSelectScene(kit, options)`, which makes the select screen of every family. Its session browses the library with the browse model of `@be-music/scene-model` and the family's select policy, keeps the play options and the option panels, shows a chart's text file, and starts a chart or a course through `on.start(entry, { autoPlay })`. It plays through the audio service: the select BGM, ducked under the chart preview, and the preview are the screen's own and stop as it leaves the stage, while the cues and the decide jingle (`sounds.decideBgm`) play out, so the jingle rings on through the decide screen into the play. The LR2 view lights the skin's ops, numbers, texts and timers through `@be-music/lr2-skin/state`. The beatoraja view draws the skin through `@be-music/beatoraja-skin/scene`; its MODE and SORT buttons step the key filter and sort kept in the browse position, and it keeps beatoraja's keys (Page Up / Page Down move ten bars, R picks a random bar, Backspace only backs out of a folder).

`SelectScene` has `snapshot()` / `restore()`, `focused()`, `getPlayOptions()` / `setPlayOptions()`, `setLibrary()`, `refreshRecords()`, `setSearch()`, `setSounds()` and `updateKit()`, and `entered` says whether it is showing. A host can edit the search query in place over the skin: `searchFieldRect()` gives the skin's search box in canvas CSS pixels (a be-music skin's `activateSearch` hit area, or an LR2 skin's `#SRC_TEXT st=30`) and `setSearchEditing(true)` hands its text to the host's field laid over it. The built-in skins split their search hit area into the label and the text strip, and Plain gains a clickable search box.

Migration:

- `new DefaultPixiSongSelectView({ beMusicSkin, beMusicEffects, beMusicSkinSettings, selectBgm, decideBgm, systemSounds, initialNavigation, initialPlayOptions, onPlayOptionsChange, resolveSongRecord, onSongSelected, onSongAutoPlay, onSearchActivate })`, then `view.setCollection(collection)` and `view.mount(host)` → `createSelectScene({ family: 'built-in', skin: beMusicSkin, effects: beMusicEffects, settings: beMusicSkinSettings }, { library: collection, browse, playOptions: initialPlayOptions, records, sounds, audio, on: { start, playOptions: onPlayOptionsChange, search: onSearchActivate } })`, then `host.setScene(scene)`, where `audio` is the host's `createAudioService()`, `sounds` a `SystemSoundSet` (`selectBgm`, `decideBgm`, `cursor`, `folderOpen`, `folderClose`, `optionOpen`, `optionClose`, `optionChange`) and `records` the best records (`{ chart, course }`).
- `new PixiSongSelectView({ skin, … })` → `createSelectScene({ family: 'lr2', skin }, { … })` as above, with `sounds` from the theme (`systemSoundSetFromLr2Theme` of `@be-music/scene-model`).
- `new PixiBeatorajaSelectScene({ skin, textures, fonts, skinConfig, songs, collection, skinAudio, systemSoundPaths, selectBgmPath, restoreSnapshot, initialIndex, resolveSongLampOp, decodeChartImages, onSongPicked, onExit, onReadtextRequest, onSkinConfigChange })` → `createSelectScene({ family: 'beatoraja', kit }, { library: collection, browse, records, sounds: systemSoundSetFromBeatoraja({ paths: systemSoundPaths, selectBgmPath }), audio, on: { start, exit, readtext, skinConfigChange } })`, where `kit` is `loadBeatorajaSceneKit`'s and `audio` has the theme's files set (`audio.setTheme({ files })`) for the path-only sounds and the skin's Lua sounds. The screen lights the bar lamps from `records` and loads a chart's images and preview from the library itself; without `on.readtext` it shows the README overlay itself.
- `onSongSelected` / `onSongAutoPlay` / `onSongPicked` → `on.start(entry, { autoPlay })`, with `entry` a `{ kind: 'chart', chart }` (or a course). Return `false` when it starts no play, and the screen plays no decide sound.
- `PixiSongSelectNavigation` (`{ folderPath, selectedIndex }`) → `BrowseSnapshot` from `@be-music/scene-model` (`{ folderPath, cursors }`, the cursor at every depth, plus the bar under the cursor, the search and the list options). `getNavigation()` / `setNavigation()` / `initialNavigation` → `snapshot()` / `restore()` / `browse`; the beatoraja scene's `captureSnapshot()` / `restoreSnapshot` / `initialIndex` / `setSelectionIndex()` → the same (`PixiBeatorajaSelectSceneSnapshot` → `BrowseSnapshot`).
- `setCollection()` → `setLibrary()`; `setSearchQuery()` → `setSearch()`; `setSelectBgm()` / `setDecideBgm()` / `setSystemSounds()` → `setSounds()` (`PixiSongSelectSystemSounds` → `SystemSoundSet`, where `cursorMove` is `cursor`).
- `setBeMusicSkinSettings(settings)` → `updateKit({ ...kit, settings })`; `setSkin(skin)` → `updateKit({ family: 'lr2', skin })`; `replaceSkin(…)` → `updateKit({ family: 'beatoraja', kit })`.
- `playDecideSound()` → nothing: the screen plays the decide jingle when a play starts.
