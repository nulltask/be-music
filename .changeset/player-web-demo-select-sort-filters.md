The Debug Menu's Play options folder gains **Sort**, **Key filter** and **Difficulty filter** for the built-in and LR2 select screens, two-way synced with an LR2 skin's sort and filter buttons, so the built-in skins, which draw no such buttons, can sort and filter their list too. The test hook's select cursor reports the list's sort, filters and search (`state().cursor.list`).
