On beatoraja's key map, SELECT + a key in a play changes how long notes stay visible by 1 ms, as beatoraja's does: odd keys and the turntable's second key shorten it, even keys and its first key lengthen it (`adjustWhiteNumber` scales the hi-speed to match). START + the turntable now moves the lane cover the way beatoraja's does: its first key covers more of the lane (it covered less).
