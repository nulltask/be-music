# n2x 実装仕様

ナナシグルーヴ2 は、譜面リストなどを `.n2x` ファイルに収録します。Be-Music は譜面リストを 1 本の EXPERT コースとして読み込みます。Toy Musical 3 では各項目が 1 ステージの選択肢になりますが、Be-Music ではリストの順に続けてプレイします。[コース仕様](./course.ja.md)

## 対応状況

| 操作              | 対応                                                     |
| ----------------- | -------------------------------------------------------- |
| リストの読み込み  | ブラウザー版のフォルダー・アーカイブ読み込み             |
| プレイ            | 全ステージの譜面がそろえば EXPERT コースとしてプレイ可   |
| ほかの n2x データ | スキン、モード、設定のファイルからはコースを作りません。 |
| n2x の書き出し    | 未対応                                                   |

## XML 入力と対応関係

`@be-music/player-engine/course` の `parseN2XCourseFile` は、XML 文字列、XML のバイト列、[ZEXA コンテナ](./n2s-spec.ja.md#コンテナ)を受け取ります。コンテナでは最初のファイルを読みます。リストは `bmslist` をルートに持ち、その子の `bms` が各項目です。

```xml
<bmslist>
  <bms><file>charts\first.n2s</file></bms>
  <bms><file>charts\second.n2s</file></bms>
</bmslist>
```

空でない `file` ごとに 1 ステージを作ります。値の前後の空白を取り、バックスラッシュをスラッシュに変え、先頭のスラッシュを取り除きます。譜面が見つかるまでは譜面ファイルの拡張子を除いた名前をステージ名に使います。コース名とグループ名にはリストの拡張子を除いた名前を使います。たとえば `amanas.n2x` は `amanas` になります。重複項目も順どおりに残し、ファイル指定のない項目を飛ばし、解禁条件は読みません。有効な項目のないファイルからはコースを作りません。[パーサーの実装](../packages/player-engine/src/course/n2x.ts)

## ステージと譜面の照合

ブラウザー版は、リストのフォルダーを基準に譜面のパスを組み立てます。まず大文字・小文字を区別せず完全一致を探し、見つからなければフォルダーの境界でパスの末尾が一致する最初のライブラリー項目を使います。どちらのパスが長い場合でも照合します。見つけた譜面にファイルハッシュがあれば、そのハッシュ、曲名、アーティスト名をステージに設定します。記録とリプレイは、ほかのコースと同じ方法でハッシュを参照します。

譜面が 1 つでも見つからなければコースは表示されますが、開始できません。ステージ数の上限はありません。Toy Musical 3 の `free` には 1,200 件以上あります。`extra1`〜`extra3` と `stagelist` は同梱されていない開発用譜面を参照するため、コースは表示されても遊べません。フォルダー構成を保ったままリストと譜面を読み込ませてください。[パス照合の実装](../packages/player-browser/src/collection/course.ts)
