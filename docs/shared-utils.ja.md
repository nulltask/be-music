# 共通ユーティリティ

`@be-music/shared-utils` は複数パッケージで再利用する汎用処理を所有します。ブラウザーや実行環境に依存しないコードでは狭いサブパスから import します。パッケージのルートには Node 専用のファイル操作やログ処理も含まれます。

| 入口      | 実行環境         | 用途                                               |
| --------- | ---------------- | -------------------------------------------------- |
| `./core`  | ブラウザー・Node | 数値の範囲制限、分数、ASCII コード、アセットとパス |
| `./hash`  | ブラウザー・Node | 同期 SHA-256 とネイティブの非同期 SHA-256          |
| `./async` | ブラウザー・Node | タイマーを注入できる、期限付きの終了待ち           |
| `./cli`   | Node             | 通常の CLI と SEA の起動判定                       |
| `./pcm`   | Node             | バッファーへのステレオ PCM16 出力                  |

## ハッシュ

`sha256Hex(text)` は UTF-8 テキストを同期的にハッシュ化します。`sha256HexOfBytes(bytes)` は型付き配列の指定範囲をハッシュ化します。`sha256HexAsync(textOrBytes)` は Web Crypto を使い、Promise を返します。どの関数も SHA-256 を小文字の十六進数で返します。決定的なフィンガープリントの構築には同期版を使い、サービスやブラウザーでのファイルハッシュにはネイティブの非同期版を使えます。既存の `@be-music/chart-model` の `sha256Hex` エクスポートも維持します。

## 終了待ちの期限

`settleWithTimeout(task, timeoutMs, scheduleTimeout?)` は終了処理が成功または失敗した場合に `true`、期限が先に来た場合に `false` を返します。同期処理や `undefined` は即座に完了します。期限は待機を打ち切り、処理自体は取り消しません。期限後の拒否も処理済みとして扱います。待機終了後にタイマーを解除します。

省略可能なスケジューラーはコールバックと時間を受け取り、解除関数を返します。プレイヤーエンジンは自身のスケジューラーを渡すため、挙動を固定するテストで仮想時間を使い続けられます。ほかの利用者は既定のホストタイマーを使います。

## CLI 起動

`isCLIEntryPoint(() => import.meta.url, options?)` はプロセスの入口ファイルを確認し、ワーカースレッドでは起動しません。モジュール URL をコールバック内で読むため、SEA/CJS バンドルで `import.meta` が使えない場合も扱えます。`allowExecutableFallback: true` はモジュール URL を使えない場合に限り `process.execPath` との一致を許可します。有効なモジュール URL が別ファイルを指す場合、このフォールバックは使いません。

## 既存の数値ヘルパー

ASCII の検証と大文字化には `normalizeASCIIBase36Code`、通常の閉区間の範囲制限には `clamp` を再利用します。形式固有の検証、丸め、排他的な上限は所有パッケージに残します。スキン作者は `@be-music/player-skin-sdk` 経由で同じ `clamp` を使い、スキンの import 契約を維持できます。PCM ライターは既存の `floatToInt16` 変換を使います。
