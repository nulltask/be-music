# 公開するエントリポイントは設計して決める。1.0 までは破壊的変更を許す

パッケージは、ファイル構成ではなく設計したエントリポイントを公開します。`@be-music/player-engine` は 13 の `core/*` サブパスを公開してホストが直接読み込み、`@be-music/player-browser` は画面の内部を再公開していました。1.0 までは、その形にするための破壊的変更を許し、minor バージョンとして、changeset に移行方法を書いて出します。リプレイの形式とフィンガープリント（`bmfp0`、`bmcourse0`）もバージョン 0 でまだ公開していないので、変えて構いません。変えるときは毎回意図して、専用のプルリクエストで、仕様書・golden の値・changeset を一緒に更新します。
