# 0024: BMS の拡張音声効果はホストのテンポ変更より前に準備する

## 背景

[MacBeat MOD の原仕様](http://harinezumi.s14.xrea.com/download/mbm.txt)は WAVCMD のピッチ・百分率音量・発音時間を定義します。従来のヘルパーコメントは、符号付きピッチ・127 基準の音量・ループ位置と誤って説明していました。[EXWAV の資料](https://hitkey.nekokan.dyndns.info/cmdsJP.htm#EXWAVXX)は周波数と左右バランスを定義しますが、MacBeat 命令との合成は定義しません。Web Audio のデコードは context のレートに変換するため、周波数指定に必要な元のレートを失います。

## 決定

browser・Node・オフライン再生で、次の Be-Music の規則を共通に使います。

| パラメーター | 規則                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------- |
| WAVCMD 00    | ピッチを 0–127 に制限し、倍率を `2 ** ((pitch - 60) / 12)` とする。                                         |
| WAVCMD 01    | 百分率音量。100 が等倍。                                                                                    |
| WAVCMD 02    | 正数は `value / 2000` 秒を発音時間の上限とし、0 は原音の終端までとする。ループや無音の追加はしない。        |
| EXWAV f      | 100–100000 Hz に制限し、ピッチ倍率へ `frequency / nativeSampleRate` を掛ける。                              |
| EXWAV p      | -10000–10000 に制限する。反対側のチャンネルだけを `10 ** (-abs(pan) / 2000)` 倍に減衰し、端では無音にする。 |
| EXWAV v      | -10000–0 に制限して 1/100 dB の減衰を適用し、最小値では無音にする。                                         |

[DirectSound の pan 資料](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee418148%28v%3Dvs.85%29)は、左右間で音を移さず片側だけを減衰させると定義します。左だけの録音を右へ振っても右へは移りません。重複 WAVCMD はスロット・パラメーターごとの後勝ちです。周波数とピッチの倍率を掛け合わせてから発音時間を制限します。この方言間の合成と処理順は Be-Music の規則であり、元プレイヤーとの完全一致を検証したものではありません。

ファイル名は `resolveBMSWAVResources` で解決します。有効な EXWAV は WAV の有無にかかわらず同じスロットを所有し、不正な EXWAV は WAV を残します。元のマップは変更しません。NONSTOP はスロットを分離し、宣言をステージ専用のアセットパスへ変換します。

効果は chart-model で解決し、実行環境に依存しない `transformStereoPCM` で PCM へ反映します。Node とオフラインは、出力レートへの変換前にデコーダーの元レートを使います。browser は周波数指定があれば Mediabunny で元レートを読み、Keep Pitch の時間伸縮より前にスロット別バッファを準備します。同じファイルでもピッチ・時間・左右バランスが異なるため、パスだけでは識別できません。準備済みキャッシュキーは base-62 のスロットの大文字・小文字を保持します。元のバッファは変更しません。

ホストのテンポ・FIT 処理は準備の後に適用します。Keep Pitch でも譜面が指定した音程は残り、発音時間はホストのテンポに従います。seek・再トリガー・pause・replay は実際の長さを持つ準備済みバッファを使います。外部でデコードした browser のバッファに EXWAV 周波数を適用する場合は、スロット別の準備済みバッファか `WebAudioSessionContext.nativeSampleRates` が必要です。元レートをデバイスのレートで黙って代用しません。

## 結果

公開型 `BmsWAVCmdParam` のコマンド 02 は `duration` とします。非推奨の byte という名前の音量ヘルパーは百分率のヘルパーへ委譲します。既存の EXWAV 音量フィールド・関数名は API 互換のため残し、数値単位は 1/100 dB とします。

線形補間は既存のオフライン変換と揃えます。デバイスや browser のリサンプリングにより個々の PCM 値は異なり得ます。テストは音程・時間・チャンネル分離・各バックエンドへの接続を検証し、browser と Node のデコード結果のビット一致は要求しません。NONSTOP はステージ別 VOLWAV と既存のスロット固有ゲインを掛け、任意の `resources.wavGain` に正確に保持します。共通のスロット音量解決で browser・Node・オフラインに一度だけ適用します。JSON はこの情報を保持します。BMS は合成ゲインを正確に再現する整数百分率がある場合だけ変換し、bmson は 1 以外を拒否します。[IR 仕様](../json-spec.ja.md#スロット固有ゲイン)を参照してください。

合成した譜面を保存しても音量を保持する必要があるため、実行時だけのステージ音量マップは採用しません。任意の IR 情報を追加することで、ゲインのない既存 JSON と元のネイティブ命令を維持します。音量の単位が粗い形式への出力には、正確に表現できる範囲を明示します。
