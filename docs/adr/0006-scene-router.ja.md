# ホストは画面の切り替えをすべて 1 つのシーンルーターに通す

Web のデモでは、1 つの**シーンルーター**が今の画面を持ちます。切り替えのたびに、録画中なら確定し、今の画面を外して破棄し、次の画面を載せます。順番はいつも同じで、切り替えは直列に処理するので、遅れて届いた非同期の処理が新しい画面に作用することはありません。コースの実行、記録とプレイログ、ライブラリ、設定、Debug Menu、テーマは別々のサービスで、`main.ts` はそれらをつなぐだけです。5,600 行のホストは経路ごとに破棄する画面の範囲が違い、プレイ中のドロップやスキンの切り替えで録画が消え、コースの実行が残って次の単曲がステージとして数えられ、F5 で AUTO とリプレイの指定が消えていました。
