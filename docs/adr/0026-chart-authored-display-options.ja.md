# 0026: 譜面の実効表示操作をユーザー設定と分けて記録する

## 背景

保存された nanasigroove の公式マニュアルは、HI-SPEED を音声の tempo とは独立した 0.25–100 の表示間隔倍率と定義しています。譜面指定は engine・browser のユーザー操作範囲を超えます。同時刻の A6 のネイティブ順序は、単純な後勝ちでは確定できません。[調査資料](../research/chart-authored-options.ja.md)に一次資料、新旧の別名、動的変更の制限、未確認の数式を記録しています。

古い replay の読み込みで、新たに対応したソース ID を実行すると、表示や将来の判定オプションが変わる可能性があります。また強制値をユーザーの view 変更として記録すると、ステージ境界や seek で上書きを解除した際に戻す設定を失います。

## 決定

解決済みの初期 OPTION 宣言と A6 を、バージョン付きの `ChartOptionProgram` にコンパイルします。version 1 は命令時刻を最も近い整数の譜面マイクロ秒へ丸め、完全な実効表示状態を持ち、現時点の実行フィールドは `hiSpeed` だけです。未知の ID、不正な値、未定義参照、動的変更できない旧別名は構造化した診断を出し、先に受理した操作を解除しません。

新形式の `774:HI-SPEED_x...` は、0.25–100 の小数第2位までを正確に受理します。数値の旧 HSP 別名は初期指定に対応し、旧 0.2 は観測された最小値 0.25 にします。A6 では旧別名を受理しません。ベンダー引数全体と大文字小文字を保持し、接頭辞のない別名を推測しません。同時刻は正規化済み IR 順で実行し、後の受理操作を優先します。これは Be-Music の規則で、ネイティブ順序の再現を示しません。

engine は譜面時計で `PlayerUIFramePayload.chartOptions` を公開します。pause は状態を保持し、seek は状態を持たない検索を使い、反転では反転時刻に固定します。practice の終了指定がなければ、最後の実行可能命令から 1 譜面秒の表示時間を確保します。HI-SPEED は音声の tempo、ノート、判定、スコア、ランキング可否を変えません。コースのユーザー速度変更禁止も、譜面の強制表示操作は抑制しません。

browser はユーザー範囲の制限、HS-FIX、classic・floating 変換、アニメーション遷移を通さず、指定倍率を直接使います。それまでの正確な hi-speed 状態を下に保持し、強制中の user・host・replay の速度変更を抑制します。解除時に元の状態へ戻し、通常の view 更新を再開します。terminal はユーザー範囲への制限や譜面指定時の最小表示幅制限をかけず、グリッドと表示値の両方へ正確な倍率を使います。browser の4系統は同じシーン状態を使います。

受理した実効操作だけを、バージョンを含む省略可能な `ReplayChart.chartOptions` に記録します。replay の厳密な検証は、未知のバージョン・フィールド、不正値、逆順の時刻を拒否します。再生はソース宣言を再解釈せず、記録したプログラムを使います。browser がプログラムのない古い replay を読む場合は、明示的に空のプログラムを渡します。ユーザーの option・view 記録は元の速度を保持し、上書きは譜面プログラムで再現します。再シミュレーションは表示操作を無視し、記録可否と fingerprint は変えません。

NONSTOP は合成した実効プログラムを `NonstopStitchMap.chartOptions`、ステージの診断を `chartOptionDiagnostics` に保持します。browser は両方を自動で渡し、Node の gameplay worker も構造化した通常のデータとして保持します。ステージの所有範囲は終了を含まないマイクロ秒単位です。先頭の切り詰めでは直前の選択を復元し、次のステージは固有の初期状態を設定します。空の状態なら前の強制値を解除します。FIT は命令の時刻をステージの rate で割り、表示倍率の値自体は変えません。元譜面が反転した後の操作は、そのステージの終了まで除外します。未対応宣言の診断にはステージ・コース時刻・元譜面時刻を保持します。

合成した replay は、この実効プログラム全体を記録します。ステージの切り出しでは、所有する命令からステージ offset を引き、FIT 適用済みの時刻を維持します。実際に遊んだ範囲の先頭を復元し、所有範囲の終了が有限なら強制状態を解除します。切り詰めて遊んでいない前方区間に、未観測の譜面操作を作りません。平坦化した譜面だけの保存では NONSTOP の表示 sidecar を保持しないため、stitch map または記録済みの実効 replay プログラムを使います。

## 結果

新しく対応した ID が、記録済みの実効プログラムで勝手に有効になることを防ぎます。0.77 や 100 の強制値を表示しつつ、永続的なユーザー設定を上書きしません。NONSTOP のステージ境界でも、空の実効状態で元の設定へ戻します。

通常再生と NONSTOP で HI-SPEED を実行します。他の系列、判定変更に対するコース制約と記録・replay 方針は #835 で追跡します。HIDDEN・CHANGE-HS・CRAZY のネイティブ数式や表示一致は主張しません。
