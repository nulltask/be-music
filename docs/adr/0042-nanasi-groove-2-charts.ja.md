# ナナシグルーヴ2 の `.n2s` 譜面を PMS として読む

Toy Musical 3 は、同梱のプレイヤーであるナナシグルーヴ2 向けの `.n2s` ファイルでしか譜面を配布していません。`.n2s` は「ZEXA」コンテナで、中身は 1 つの普通の PMS 譜面です。それを zlib で圧縮し、プレイヤーに埋め込まれた固定の鍵と IV で AES-128-CBC 暗号化しています。コンテナの構造は [format-compat §2.20](../format-compat-bms.ja.md#220-ナナシグルーヴ2-の-n2s-コンテナ) にあります。

`@be-music/chart-parser` はコンテナを自分で開き（`parseN2SBytes`）、中の PMS ファイルを `.pms` ファイルと同じように読みます。そのため鍵と IV はこの公開リポジトリに含まれます。別のツールで先に復号してもらう方法では、ほとんどのプレイヤーが Toy Musical 3 を遊べないままになるので、メンテナはファイルを直接読むことを選びました。

拡張子がレーン構成の入力になるところ（`isPMSChartPath`）では、`.n2s` を `.pms` として扱います。対象はプレイモードの判定、9 KEY の配置、fingerprint です。`.n2s` 譜面と、その中の `.pms` ファイルは同じ fingerprint になります。

5 ボタン譜面は、中央のレーン `13`〜`15` と `22`〜`23` だけを使う PMS ファイルです。ナナシグルーヴ2 もこれを 9 ボタンの配置で遊ばせるので、Be-Music に専用のモードは要りません。譜面と一緒に置かれた `.n2x` のリストや設定（コースの一覧、解禁条件、レベルの上書き）は読みません。ただし譜面リスト（`bmslist`）は、解禁条件を除いてコースとして読みます（[course.ja.md](../course.ja.md#ナナシグルーヴ2-の-n2x-譜面リスト)）。
