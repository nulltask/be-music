# 0028: PLAYER ヘッダの実行を明示的な選択にする

## 背景

公式 BM98・BM98k マニュアルは PLAYER 2 を二人用・COUPLE、PLAYER 4 を BATTLE と定義します。一方、現代の譜面作者は通常の SP・DP・PMS にも PLAYER 2 を使っています。元の 2,748 ファイルで見つかった PLAYER 2/4 の20件はすべて PLAYER 2 でした。8件は PMS 9KEY、4件は SP 7KEY、8件は beat 系の二側配置で、作者の readme・難易度名は19件を SP・DP・9KEY と明記しています。残る TP 譜面には別の DP 譜面と二人用譜面の担当表記があります。既定で文字通り推定すると作者が示したモードを変えてしまいます。[調査資料](../research/player-header-modes.ja.md)に一次資料、全ファイル名、件数を記録します。

Be-Music には独立した二人分の判定・ゲージがあります。既存の TWO-PLAYER は SP を両側に複製し、二側配置はそのまま保持します。COUPLE は SP でも空の作者指定側を保持し、譜面を複製しない必要があります。replay とスキン選択も同じ決定を使う必要があります。

## 決定

OFF の既定値と保存済みの選択を維持します。AUTO（browser 設定の表示は CHART HEADER）と、明示的な COUPLE を追加します。AUTO は分岐選択後の BMS PLAYER を解釈し、他の明示的な選択を上書きしません。bmson、LR2 以外のルールセット、コースのステージ、beat 5・7・10・14KEY 以外では無効です。これは実測された作者の使用法に基づく互換方針であり、原仕様の PLAYER 2 が一人用を意味するという主張ではありません。

| 選択                              | 実効的な実行                                  |
| --------------------------------- | --------------------------------------------- |
| OFF                               | 通常の一人用の解釈を維持                      |
| AUTO + PLAYER 2                   | COUPLE: 各プレイヤーが作者指定の側を担当      |
| AUTO + PLAYER 4                   | TWO-PLAYER: SP は複製し、二側配置は両側を保持 |
| AUTO + その他・未指定の PLAYER    | OFF                                           |
| 明示的な COUPLE・TWO-PLAYER・変換 | PLAYER と独立した既存の使用可能条件           |

COUPLE は LR2 の beat 配置に対応します。SP は対応する10・14KEY 配置にし、2P 側は空のままにします。判定ノート・地雷・不可視ノート・音声トリガーは複製しません。二側配置は内容を保持し、各プレイヤーが独立したスコア・ゲージ・入力を持ちます。コースの制限は維持します。PLAYER 4 の二側配置を保持するのは Be-Music の明示的な方針です。一次資料は独立した2Pオブジェクトを破棄する規則を示しておらず、ネイティブの上書き動作との厳密な一致は主張しません。

決定的な `resolveEffectiveBattleMode` を engine の lanes エントリから公開し、準備処理と LR2 スキン選択が使います。AUTO は要求であり、記録する実効配置ではありません。replay は COUPLE・TWO-PLAYER・OFF を記録し、typed `play.battleMode` の AUTO はパーサーで拒否します。古い replay と以前の配置のモードが未指定なら、現在の設定や元譜面のヘッダによらず OFF を維持します。

replay シミュレーションは COUPLE・TWO-PLAYER では既定で1Pを計算し、`player: 2` で2Pを選びます。2Pのゲージを使い、正規化済みノート・入力を側ごとに選び、元の replay は変更しません。以前は両側を合算していた計算を修正します。二人分のローカル結果と共通 replay は保持します。既存の browser 結果処理は2Pがある場合に一人用ベスト記録を更新しません。オンラインの eligibility も二人プレイを `two-player` で拒否し、譜面の片側や二人の合計を一人のスコアとしてランキングへ混ぜません。新たな二人用ランキングは追加しません。

## 結果

実測した20譜面は既定の挙動を保持します。DP と明記された7件も含め、ヘッダ解釈には明示的な選択が必要です。実際の TP 候補は各240ノートで完走し、正規化済み replay の再計算も両側で一致します。PLAYER 2/4 の構文は BMS の20/2,720件（0.74%、全体20/2,748件で0.73%）にあり、二人用の明示的な根拠があるのは1件（どちらの分母でも0.04%）です。これはファイル単位の兆候で、20件の再生不具合を示すものではありません。#837 の他の方針項目は引き続き未完了です。
