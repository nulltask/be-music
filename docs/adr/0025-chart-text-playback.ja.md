# 0025: 譜面テキストは engine の時刻と判定エフェクトに従う

## 背景

[TEXT 命令の観測資料](https://hitkey.nekokan.dyndns.info/cmdsJP.htm#TEXTXX)では、pomu のチャンネル `99` による選択、空または未定義参照による消去、nanasigroove の `TEXT00` によるミステキストを確認できます。ただし、ミス表示の寿命や再生中の全操作との関係は定義されていません。定義の保持だけではテキストが表示されず、`99` を音声チャンネルとして扱うと同じスロットの別の WAV を鳴らす可能性もあります。

## 決定

通常の選択を chart-model の `buildChartTextTimeline` と `pickChartText` で解決します。engine は選択したプレーン文字列を省略可能な `PlayerUIFramePayload.chartText` に公開します。フレームの値が未指定または空なら表示を消します。テキストは判定・スコア・replay 入力・音声トリガーに影響しません。

ネイティブの挙動が未確定の部分には、次の Be-Music の表示規則を適用します。

- 最初のチャンネル `99` の選択前は通常テキストを空にします。`TEXT00` はミス時の上書きであり、初期表示には使いません。
- POOR BGA を開始・解除する実際の判定エフェクトでミス表示を制御します。上書きは譜面時刻で 0.5 秒間とし、終了時刻を含めません。それより早い解除エフェクトでも終了します。`TEXT00` がなければ通常テキストを維持し、明示的に空なら一時的に隠します。
- ミス表示中もチャンネル `99` は通常の選択を更新します。解除・期限切れの後は現在の譜面時刻で選択されるテキストに戻します。
- pause は選択とミス表示の寿命を保持します。manual seek は過去のライブ判定を破棄し、AUTO・replay seek は無音の判定エフェクトから再構築します。再スタートは新しい状態で始めます。
- 負 BPM による反転では、選択とミス状態を反転時刻で固定し、それ以後の判定入力を無視します。
- practice の範囲指定がない場合、最後に実行できるテキストの選択から最低 1 譜面秒まで再生を継続します。最後が消去でも同じです。最後のノートより後にある命令もホストが表示できます。

browser の native・Canvas・LR2・beatoraja は、ポインター操作を遮らない共通のオーバーレイを使い、HTML として解釈せず文字列を表示します。幅はステージの 90% で折り返し、高さは 30% 以内に収めます。terminal は幅で切り詰める専用の `TEXT` 行を確保し、改行や端末制御文字で画面配置が変わらないようにします。この配置は Be-Music の UI 規則であり、ネイティブプレイヤーの配置との一致を示しません。

## 結果

各ホストで同じ譜面時計と判定履歴を使います。タイマーや replay スキーマの追加は不要です。元の定義・引用符・未知の命令は書き出しで変更しません。歴史的な `#SONGxx` の方針は #837 で追跡します。NONSTOP のステージごとのテキスト所有権は #834 で合成対応を続けます。平坦化した譜面だけを渡しても、ステージごとの `TEXT00` 定義は維持できません。
