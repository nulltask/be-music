# 0022: bmson の条件付き BGA イベントは決定的な譜面時刻で動かす

## 背景

beatoraja の bmson デコーダーはシーケンス候補・条件・間隔を保持する一方、描画処理は MISS レイヤーに限られ、PLAY／ALWAYS のイベントレイヤーと interval を実行しない。保持だけを移植しても、これらの機能は動かない。2026-10-29 にユーザーは、上流の未実装部分へ Be-Music の実行規則を文書化して導入する方針を選んだ。上流の参照先とリソース id の規則は[シーケンスデータ仕様](../bmson-spec.ja.md#beatoraja-の-bga-シーケンスデータ)に記載する。

## 決定

決定的な engine がアクティブなシーケンスを管理し、ファイル名・表示面・フレーム開始時刻を `PlayerUIFramePayload.bmsonBGA` に公開する。ホストは候補フレームの参照先をすべて読み込み、公開された状態を通常の BGA 合成で描く。この表示状態は判定・スコア・音声・記録する入力列を変えない。

| 条件                      | 開始契機                                                | 正の `interval` の意味                                  |
| ------------------------- | ------------------------------------------------------- | ------------------------------------------------------- |
| `play`                    | PERFECT・GREAT・GOOD の判定                             | 受理する開始同士の最小間隔（ミリ秒）                    |
| `miss`                    | BAD・POOR・地雷を含む、既存 engine の POOR-BGA トリガー | 受理する開始同士の最小間隔（ミリ秒）                    |
| `always` または未知の条件 | 選択の譜面時刻                                          | 指定した譜面ミリ秒ごとに繰り返し開始。ゼロなら 1 回だけ |

interval とシーケンスのフレーム時刻には譜面ミリ秒を使う。一時停止中は進まず、テンポ変更では譜面とともに伸縮する。layer の interval 省略時はゼロ。POOR イベントは上流と同じく MISS・interval 1・単一 id 参照に固定する。開始が受理されるたびに `id_set` を定義順に巡回し、間隔制限で無視したトリガーは選択を進めない。ホストは明示的な候補番号をコントローラーへ渡してもよい。隠れた時計や乱数は選択に使わない。

新しい選択は前のアニメーションを終了し、候補の巡回番号をリセットする。通常の画像レイヤーへの変更も、それ以前のイベント選択を解除して通常の画像タイムラインへ戻す。同じ譜面時刻では選択を判定より先に適用し、選択同士は定義順に処理する。成功判定はアクティブな MISS アニメーションを消す。MISS は通常の BGA スタックを置き換え、PLAY／ALWAYS はレイヤー面を使う。終端は次の開始が受理されるまで終了状態を保ち、欠落画像を別の id で補わない。

手動 seek では過去のライブ判定履歴を捨てる。AUTO とリプレイの seek では、スコアを再構成する同じ無音の判定エフェクトから表示入力も復元し、地雷の POOR トリガーも保持する。逆再生開始点で選択とシーケンスのフレーム切替を固定し、すでに選ばれた動画はホストの既存の動画時計で再生する。コントローラーを過去の時刻で参照すると、保持した入力を折り畳み直し、同じフレームを再現する。

## 結果

上流の未実装部分について、beatoraja と同じピクセルやトリガーになるとは主張せずに、実際に動くイベント規則を実装する。表示の規則なのでリプレイのスキーマに項目を足さず、再現した判定からシーケンスの候補を復元する。engine・Terminal・Browser の 4 種類のスキンに状態の経路を実装する。Browser は画像セットのすべての候補を事前に読み込み、base／layer／POOR の動画再生位置を独立させる。条件付き MISS の定義は以前の通常 POOR 定義を解除し、終端後の再表示を防ぐ。通常の画像レイヤーでは、標準 bmson の独立した POOR チャンネルを保つ。NONSTOP の配置は、結合テストが通るまで #826 の残作業とする。
