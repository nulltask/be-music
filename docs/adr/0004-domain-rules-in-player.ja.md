# コース・記録・ランプの規則は @be-music/player に置く

コースの実行（ステージの計画、持ち越し、投げ、結果）、NONSTOP の流れ（準備、結合、コースのプレイログの組み立て）、コースのステージの規則、クリアランプと BP、判定ルールセットごとの自己ベストの統合は、実行環境に依存しない規則として `@be-music/player` に置き、すべてのホストとリーダーボードが使います。これらは Web 層・デモ・リーダーボードに散らばっていました。検証が通るには一致しなければならない NONSTOP の流れが 2 つ、クリアランプの規則が 2 つあり、コースを遊べるのは Web のデモだけでした。そのためターミナル版ではコースを遊べず、規則を 1 つ変えるたびに複数の場所を直す必要がありました。
