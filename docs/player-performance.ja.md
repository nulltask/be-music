# ブラウザプレイヤーのパフォーマンス計測

[English](./player-performance.md)

#344（Lua のメモ化）と #345（プレイ中のメモリ確保）を調査した記録です。基準は `8e4bdb15`、描画の変更は `13eaa2a7` と `76110dd3` です。この変更は PR #681 のシーンタイマー対応に依存します。

## 計測条件

Apple M5、メモリ 32 GB、macOS 27.0.1（26A434）、Node 26.12.1、pnpm 10.30.3、Playwright Chromium 156 で計測します。ブラウザは 1280 × 720、デバイス倍率 1、GPU 描画、CPU 制限なしです。ブラウザのワーカーは 1 つにし、計測中は全体ビルド、テスト、ベンチマークを並行実行しません。

譜面は 150 BPM、64 小節、1,024 ノーツ、7 鍵盤とスクラッチです。各スキンで AUTO を譜面時刻 5 秒まで進め、15 秒間の計測を連続して 3 回行います。Synesthesia はエフェクトを full にします。Native は DOM と Canvas、LR2 は標準テーマ、beatoraja は ModernChic の既定プリセットを使用します。スキンの素材は変更しません。選曲では異なる譜面として 300 件をドロップした後、50 ms 間隔で 150 回スクロールします。

各区間で CDP の CPU サンプル、Performance 指標、16 KiB 間隔のメモリ確保サンプル、描画間隔、スクリーンショットを保存します。メモリ計測には minor / major GC で回収されたものも含めます。最初の描画間隔は除外します。メモリ量はゴミも含む累積確保量の推定であり、保持中のヒープ量ではありません。計測自体にも負荷がかかり、共有デスクトップ上の小さな時間差から FPS の改善は判断できません。

## 再実行

ワークスペースの依存関係と Playwright Chromium をインストールします。`PERF_MODERN_CHIC` にローカルの ModernChic ディレクトリ、`PERF_LR2_FILES` に標準の `LR2files` ディレクトリを設定し、実行します。

```bash
PERF_OUTPUT=tmp/remaining-work/performance/current pnpm exec playwright test -c scripts/performance/browser.config.ts
```

専用のプレイヤーをソースマップ付きでビルドし、空いているローカルポートで配信します。一時ディレクトリに作る譜面は終了後に削除します。既存の開発サーバーやブラウザのタブには触れません。対象を絞る場合は `PERF_FAMILIES=built-in,native,lr2,beatoraja` から必要なファミリーをカンマ区切りで指定します。その場合、選曲の計測は省略します。

リビジョンごとに出力先を分けます。次のビルドで上書きする前に `packages/app-play/dist/assets/*.map` も保存します。`.cpuprofile` と `.heapprofile` をブラウザの開発者ツールで開くと、処理別の内訳を確認できます。`summary.json` には描画間隔の分位点、遅いフレーム数、Performance 指標、ブラウザエラーを保存します。区間ごとのスクリーンショットと描画間隔の生データも残ります。計測スクリプトのない古いリビジョンと比較する場合は、`scripts/performance/` をそのワークツリーへコピーしてから実行します。

ラベルの小規模な比較は `node scripts/performance/frame-labels.ts` で実行します。ウォームアップ後、100 万回の文字列生成とキャッシュ参照を、順番を交互にして 5 回測ります。時間は参考値とし、描画全体のメモリ確保プロファイルで効果を判断します。

## Lua のメモ化は見送り

ModernChic で Lua が占める時間は、実行中の JavaScript の約 4% でした。3 秒間の調査ではコールバックを 3,620 回評価しましたが、キャッシュの参照対象となる呼び出しもヒットも 0 回でした。同じ参照が共有される最大数は 8 ですが、今回の既定プリセットのプレイ中には繰り返し実行されませんでした。

副作用を保守的に観測する試作では、Lua の時間とメモリ確保が増えました。同じ条件の 15 秒間を 3 回比較した結果です。

| 指標                   | 基準                  | 試作                  |
| ---------------------- | --------------------- | --------------------- |
| Lua の CPU 時間、ms    | 79.1 / 50.7 / 70.6    | 115.7 / 94.3 / 98.5   |
| メモリ確保の推定量、MB | 128.9 / 127.5 / 128.9 | 151.7 / 150.1 / 152.5 |

対象を限定した試作でもヒットはなく、一貫した改善は得られませんでした。Lua のコールバックは捕捉した値やテーブルを書き換えたり、間接的にタイマーや音声を操作したりできます。これらを検出すると実装と実行時の負担が増えます。ユーザーの判断により結果を記録し、#344 のキャッシュ導入は見送ります。描画の変更には、メモ化、Lua VM 内部の調査処理、ランタイムの分割を含めません。他のスキンやプリセットでは結果が異なる可能性があるため、再検討時には計り直します。

## プレイ中のメモリ確保

読み手を確認すると、プレイのバインディングや外部スキンのコールバックが公開済みフレームを保持できました。描画のたびに新しい HUD のスナップショットと公開配列を作り、同じ描画内でだけ Canvas と DOM の HUD 計算を共有します。前のフレームを書き換えません。

デバッグ用ラベルはリリース時も全文を保持します。ビューまたはスキン要素を所有者とする弱参照のキャッシュに、入力値ごとのラベルを保存します。キャッシュのキー用文字列は作らず、所有者とともに解放できます。粒子描画では表示中の配列の変わらない先頭部分を保持し、同じ色と不透明度の設定を省きます。色の内部値、不透明度の制限、描画順、形状は維持します。

以下は 15 秒間の計測 3 回の中央値です。MB は十進表記です。

| スキン      | 確保量・変更前、MB | 変更後、MB | JS 実行時間・変更前、ms | 変更後、ms |
| ----------- | -----------------: | ---------: | ----------------------: | ---------: |
| Synesthesia |            4,211.3 |    3,914.9 |                 5,471.8 |    5,281.5 |
| Native      |              37.18 |      36.50 |                 1,830.1 |    1,613.6 |
| LR2         |              66.13 |      61.96 |                 1,765.6 |    1,711.6 |
| ModernChic  |             128.58 |     130.32 |                 2,044.0 |    1,704.5 |

今回、Synesthesia の確保量は約 7.0%、LR2 は約 6.3%、Native は約 1.8% 減りました。ModernChic はラベル・HUD の変更対象ではなく、確保量の 1.3% 増加はサンプリングの変動範囲です。CPU 時間は実行ごとに変わるため、ModernChic の時間短縮を今回の効果とは判断しません。どの場面でも描画間隔の 95 パーセンタイルは約 16.67 ms でした。3 区間合計で 33.4 ms を超えたフレームは、Synesthesia が 4 → 4、Native と LR2 が 0 → 0、ModernChic が 1 → 0 です。FPS が改善したとは判断しません。

選曲は比較の対照です。一括ドロップは 323 → 314 ms、確保量は 54.88 → 56.12 MB、スクロールは 8,914 → 8,938 ms、確保量は 1,999.00 → 1,995.04 MB でした。どちらも今回の最適化対象ではありません。全区間でブラウザエラーはありませんでした。ラベルの 5 回の小規模比較では、100 万回当たりの中央値が文字列生成 13.32 ms、キャッシュ参照 13.00 ms で、個々の値には重なりがあります。

元の計測データと比較結果はローカルの `tmp/remaining-work/performance/` に保存します。Lua の試作は PR に含めません。今回の計測は iOS 実機の性能を示すものではなく、iPad で描画解像度がフレームレートを制限するという既存の知見を置き換えません。
