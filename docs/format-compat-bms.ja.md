## 2. BMS

LR2、beatoraja、Be-Music で、同じ BMS 譜面をどう読み込み、再生するかを比較します。

### 2.1 行の解釈とヘッダ

**コマンドの大文字小文字**

- **de jure** 区別しない（BM98）。cmds は、一部のプレイヤーが場所によって区別する（`#LNOBJ` の値など）と注記している
- **LR2** 解析前に行全体を大文字化する。ID も含む [R]（[OpenLR2 L25950][olr2-upper]）
- **beatoraja** コマンドとチャンネルは区別しない [V]（[BMSDecoder L487-500][j-reserve]）
- **Be-Music** コマンドとチャンネルは区別しない。ID は [§2.3](#23-オブジェクト-id-と-base-62) のとおり（[`parser.ts`][bm-parser]）

**行頭の空白**

- **de jure** 未定義。cmds（[`#INDENT-STYLE`][cmds-indent]）にプレイヤーごとの表がある
- **LR2** タブと半角スペースは可、全角スペース（U+3000）は不可 [C]。解析前に行をトリムする [R]
- **beatoraja** 除去しない。字下げした行は無視される [V]（[BMSDecoder L189-194][j-lines]）
- **Be-Music** トリムするので、字下げしたコマンドも受け付ける（[`parser.ts`][bm-parser] `parseBMS`）

**ヘッダの区切り**

- **de jure** 慣習として半角スペース 1 つ（cmds）
- **LR2** 多くのヘッダを末尾のスペース込み（`"#TOTAL "`）で照合する [R]
- **beatoraja** コマンド名の 1 文字後から引数とみなし、その文字が何かは問わない [V]（[BMSDecoder L366-375][j-arg]）
- **Be-Music** 空白が 1 文字以上必要。`#TITLE:abc` はヘッダにならない（[`parser.ts`][bm-parser] `parseHeaderDirectiveLine`）

**`#` で始まらない行**

- **de jure** 無視する。これがコメントの仕組み（BM98）。`;` や `//` のコメントは IIDXv / HDX の拡張（[`#COMMENT-SYNTAX`][cmds-comment]）
- **LR2** 無視する [R]
- **beatoraja** 無視する。ただし `%key value` / `@key value` は追加の値として保持する [V]（[BMSDecoder L378-388][j-values]）
- **Be-Music** 無視する

**ヘッダの重複定義**

- **de jure** BM98 では未定義。cmds（[`#BEHAVIOR-IN-GENERAL-IMPLEMENTATION`][cmds-general]）：EOF に近い行が勝つ。繰り返せるコマンド（`#STP`、`#WAVCMD`、制御構文）は例外
- **LR2** 後勝ち [C]
- **beatoraja** 後勝ち [V]（[BMSDecoder L282-315][j-dup]）
- **Be-Music** 制御構文をまたいでもファイル順で後勝ち。選ばれた `#RANDOM` / `#SWITCH` の分岐内の定義は、前にあるトップレベルの定義に勝ち、後にあるものに負ける（[§2.14](#214-制御構文)）

**オブジェクト行の重複（同じ小節・チャンネル）**

- **de jure** cmds：行は統合され、同じ位置では後の非 `00` オブジェクトが前のものを上書きし、`00` は上書きしない。BGM（`01`）の行は積み重なる。検証したプレイヤーの約半数はこれを満たさない
- **LR2** すべてのオブジェクトを集める。1 つの位置に 2 つのノートがあるとき LR2 がどう扱うかは確認できなかった。cmds は地雷行の重複で不具合を報告している [C]
- **beatoraja** 演奏チャンネルは後のオブジェクトが前のものを置き換え、警告を出す。`01` は積み重なる。`03` / `08` / `09` は位置ごとに 1 つ [V]（[Section L353-403][j-section-notes]）
- **Be-Music** 通常ノートチャンネルでは、選択された制御構文の分岐も含め、同じ位置の後の非 `00` オブジェクトが前の定義を置き換える。置き換えられたキー音は鳴らない。専用ロングノートの開始位置に残った通常ノートは、キー音が異なる場合に BGM として鳴る。行順のない旧 JSON には従来の解決規則を適用する。 地雷と不可視オブジェクトはまとめない。BGM は積み重なる（[`resolved-notes.ts`][bm-resolved-notes] `resolveJudgedNotes`）。タイミングのオブジェクト（`03` / `08` / `09` / `SC` / `SP`）は同じチャンネル内でファイル順を保ち、beatoraja と同じく後の行が勝つ（LR2 は同じチャンネルの重複を未定義とする）。同じ位置の `03` と `08` は LR2 と同じく `08` が勝ち、重複した STOP は 1 回だけ適用する（[`beats.ts`][bm-beats] `compareEvents`、#133）。タイミングのオブジェクトは分岐外のものに分岐内のものを追加する。

**壊れたオブジェクトデータ**

- **de jure** 未定義（cmds）
- **LR2** 確認できなかった
- **beatoraja** 確認できなかった
- **Be-Music** 最初の空白でデータを打ち切る。ID に使えない文字はスロットを消費せずに読み飛ばす。末尾の余った 1 文字は捨てる（[`event-utils.ts`][bm-event-utils] `collectNonZeroObjectTokens`）

**小節番号**

- **de jure** `000`〜`999`（BM98）
- **LR2** `#000` の先頭にノートがあると、LR2 はその前に空の小節を挿入する [C]
- **beatoraja** 特別な処理は見当たらない
- **Be-Music** `000`〜`999`。特別な処理はない

### 2.2 文字コード

- **de jure** 未定義。cmds（[`#CHARSET`][cmds-charset]）：ほとんどのファイルは Shift_JIS で、安全なのは ASCII だけ。`#CHARSET` は ruv-it! のコマンドで、2.0b5p2 から廃止
- **LR2** Shift_JIS のみ。ISO-2022-JP や EUC-KR のファイルは化ける [C]
- **beatoraja** まず BOM、次に先頭 64 KiB を EUC-KR、MS932、UTF-8、UTF-16、UTF-32 の順に往復変換で試し、どれも合わなければ MS932。`#CHARSET` は読まない [V]（[BMSDecoder L535-654][j-charset]）
- **Bemuse** `bemuse-chardet`（UTF-8、UTF-16、Shift_JIS、EUC-KR）。ファイル名（`.sjis.`、`.euc_kr.`、`.utf8.`）で指定もできる [V]
- **Be-Music** BOM、`#CHARSET` 宣言、ASCII のみなら UTF-8、厳密な UTF-8 検証、韓国語の EUC-KR（beatoraja の判定と同じく非 ASCII のバイトがすべて KS X 1001 の 2 バイトの組になり、かつ文字の 90 % 以上がハングル音節）、Shift_JIS / UTF-8 / EUC-JP / Latin-1 のスコアリングの順（[`bms-text-decode.ts`][bm-decode]、[`bms-charset.ts`][bm-charset]。[BMS 実装仕様 — 文字コード](./bms-spec.ja.md#文字コード) も参照）。`#CHARSET EUC-KR` / `CP949` も読む。ハングルの割合の条件は、バイトが KS X 1001 にも当てはまる Shift_JIS の半角カナを韓国語と読まないためのもので、beatoraja にはこの区別がない

### 2.9 STOP と `#STP`

**`#STOPxx` の単位**

- **de jure** cmds（[`#STOPXX`][cmds-stop]）：全音符（4/4 の 1 小節）の 1/192。チャンネル `02` の影響を受けない
- **LR2** 同じ。値を整数として読むので小数は切り捨て [R]（[OpenLR2 L26324-26331][olr2-headers]）
- **beatoraja** 1 小節の 1/192 を、その位置の BPM で換算 [V]（[Section L299-318][j-section-stop]）
- **Be-Music** 同じ単位。小数も保つ。同じ位置の BPM 変化も含め、その位置で有効な BPM で換算する（[`timing.ts`][bm-timing] `createStopPoints`）

**負や 0 の STOP**

- **de jure** 未定義。cmds にプレイヤーごとの違いがある
- **LR2** 0 より大きい値だけを格納するので、スロットは初期値の `-1.0` のまま残る [R]（[OpenLR2 L25773][olr2-stop-slot], [L26324-26331][olr2-headers]）。値にかかわらず STOP は `-1/192` 小節を足し、その後のものがその分だけ早まる [R]（[OpenLR2 L26666-26669][olr2-stop-case]）。0 や負の再定義は先の正の値を残し、未定義の参照も `-1.0` を読む [R]。cmds は少しスキップすると報告している [C]
- **beatoraja** 絶対値を使い、警告を出す [V]（[BMSDecoder L316-334][j-stop]）
- **Be-Music** `#STOPxx` が正でない（0・負・未定義の）STOP は LR2 と同じく、その位置で有効な BPM での `-1/192` 小節とし、同じ位置では最後のものが勝つ規則にも加わる。後から書いた 0 や負の `#STOPxx` は正の値を上書きしない（[`timing.ts`][bm-timing] `collectStopChanges`、[`bms-headers.ts`][bm-bms-headers]）（Qwilight は譜面をエラーにし、Bemuse は時間を差し引く [V]）

**同じ位置の複数の STOP**

- **de jure** BMS では未定義。bmson では加算（L498-503）
- **LR2** 最後のものが勝つ [R]（[OpenLR2 L26666-26670][olr2-stop-case]）
- **beatoraja** 位置ごとに 1 つ。後勝ち [V]
- **Be-Music** BMS では LR2 や beatoraja と同じく最後のものが勝つ（[`timing.ts`][bm-timing] `createStopPoints`）。bmson の `stop_events` と `#STP` の行は加算する

**STOP と同じ位置のノート**

- **de jure** cmds：音、BPM 変化、停止の順。bmson（L505-542）：停止の始まりで叩く
- **LR2** 停止の前に叩く。停止はその位置のオブジェクトの後に加わる [R]（[OpenLR2 L26494-26527][olr2-stop]）
- **beatoraja** 停止の始まりで叩く [V]（[Section L542-562][j-section-time]）
- **Be-Music** 停止の始まりで叩く。停止は厳密に後にあるものだけを遅らせる（[`timing.ts`][bm-timing]）

**`#STP xxx.yyy ms`**

- **de jure** cmds（[`#STP`][cmds-stp]）：bemaniaDX。繰り返すと加算
- **LR2** 非対応 [C]
- **beatoraja** 非対応 [V]
- **Be-Music** 対応。同じ位置の停止は加算する（[Player 実装仕様 — 実行フロー](./player-spec.ja.md#実行フロー)）

**STOP の長さの精度**

- **de jure** 未定義
- **LR2** 未確認
- **beatoraja** 停止ごとに整数マイクロ秒へ切り捨てる（`(long)` キャスト）[V]（[Section L315][j-section-stop-cast]）。停止が多い譜面ではノートの時刻が早くずれる：Labyrinth で 0.151 ms、safe_state で 0.863 ms、"the life" の 5,704 個の停止で 3.36 ms
- **Be-Music** 意図して正確な値（倍精度）を保つ。譜面の数値が表す時刻そのものであり、ずれも判定幅よりはるかに小さい（[`timing.ts`][bm-timing]）

### 2.10 SCROLL と SPEED

`#SCROLLxx`（チャンネル `SC`）も `#SPEEDxx`（チャンネル `SP`）も、どの de jure の資料にもありません。beatoraja と Bemuse に由来します。

**LR2**

- **SCROLL** 非対応 [I]
- **SPEED** 非対応 [I]

**beatoraja**

- **SCROLL** 区間ごとの段階的な倍率。0 や負の値も受け付ける [V]（[LaneRenderer L314-321][b-lane]）
- **SPEED** オブジェクト間を時間について線形補間する。最初のオブジェクトより前は時刻 0 の 1.0 から変化する [V]（[LaneRenderer L259-286][b-lane-speed]）

**その他**

- **SCROLL** Qwilight と raindrop は SCROLL に対応 [V]
- **SPEED** Bemuse は間隔の係数として対応し（Be-Music が従うモデル）、最初のオブジェクトより前は最初の値を保つ。Qwilight と raindrop は非対応 [V]

**Be-Music**

- **SCROLL** 段階的な倍率。ノート・地雷・小節線は beatoraja の `LaneRenderer` と同じく、判定ラインの位置から譜面を順にたどり、最初にレーン上端を越えた位置で打ち切って描く。その先は、後の負の値でレーン内に戻ってくるノートも描かない（[`note-draw-window.ts`][bm-note-draw]）。負の値はノートを逆向きに動かす。Web プレイヤー では、時刻がまだ先のノートが判定ラインより下に来ればそこに描く（beatoraja も切り取らずに描く）。terminal player は距離の絶対値で動かす（逆走はしない）。`SCROLL 0` で 1 つのセルに重なったノートは順序を保つ（[BMS 実装仕様 — SCROLL/BPM/STOP 互換ポリシー](./bms-spec.ja.md#scrollbpmstop-互換ポリシー)）
- **SPEED** キーフレーム間を拍について線形補間する。最初のキーフレームより前は、beatoraja が時刻 0 の 1.0 から変化させるのと同じく、拍 0 の 1.0 からそのキーフレームの値まで変化させる（位置 0 のキーフレームはすぐに効く）。最後の値はそのまま保つ。beatoraja は時間について補間し、その時点の値をレーン全体に掛ける。Be-Music はレーンに沿って拍について補間する（[`scroll-distance.ts`][bm-scroll]）

### 2.11 小節長と `#BASEBPM`

チャンネル `02`（cmds [`#BMS`][cmds-bms]）：1 が 4/4、小数も可、その小節だけに効く。
LR2 は 4999 小節までで 0 より大きい値を受け付けます [R]（[OpenLR2 L26189-26193][olr2-measure]）。beatoraja は 0 より大きい有限の値なら上限なく受け付けます [V]（[Section L87-101][j-section-len]）。
Be-Music は beatoraja と同じく、0 より大きい有限の値ならどれだけ小さくても受け付け、後の定義が勝ちます（[`event-utils.ts`][bm-event-utils]）。

`#BASEBPM` は LR のコマンドで、LR2 では対応が外された可能性があります（[`#BASEBPM`][cmds-basebpm]）[C]。beatoraja は読みません [V]。
Be-Music は web プレイヤーのハイスピード固定の基準 BPM にだけ使い、タイミングには使いません（[`chart/src/reference-bpm.ts`][bm-reference-bpm] `resolveChartReferenceBPM`）。

### 2.19 アセットファイルの探し方

譜面はキー音や画像をファイル名で指定するが、パッケージは別の拡張子で同梱していることが多い（`.wav` と書かれた `#WAV` に `.ogg`、`.bmp` や `.mpg` と書かれた `#BMP` に `.png` や `.mp4`）。また差分は、使うファイルのあるフォルダの下のサブフォルダに置かれていることが多い。
探し方を決めた仕様はない。cmds（[`#WAVXX-ALTERNATIVE-SEARCH`][cmds-wav-alt]）は、書かれた名前を最初に探し、次に同じ名前で種類の違うファイルを探す（順番は各プレイヤー次第）とだけ述べている。狙いは、譜面の MD5 を変えずにパッケージの WAV を OGG に差し替えられるようにすることである。

**探すフォルダ**

- **de jure** 未定義。cmds は、LR2 が相対パスで見つからないとき別のディレクトリも探すと記す
- **LR2** 譜面のフォルダ、次にその親（`..\`）を同じ規則で [R]（[LR2f.cpp L14607-L14726][olr2-find-alt]）
- **beatoraja** 譜面のフォルダのみ。名前自体に書かれた `..\` は効く [V]（[SongResources L107-L108][b-song-resources]）
- **Be-Music** LR2 と同じ：譜面のフォルダ（とドロップしたものの最上位）、次にその親を同じ規則で。譜面のフォルダですべての拡張子を試してから親へ進む。サブフォルダにある差分も、親フォルダのファイルを見つけられる（[`collection.ts`][bm-collection] `resolveChartAsset`、[`sample-path.ts`][bm-sample-path] `resolveSamplePath`）

**キー音（`#WAV`、bmson の音声名）**

- **de jure** cmds：書かれた名前を最初に、次に同じ名前で種類の違うファイル（[`#WAVXX-ALTERNATIVE-SEARCH`][cmds-wav-alt]）。bmson：拡張子は省略してよく、指定したファイルがない・再生できないときは拡張子がないものとして扱う（L576-L581）
- **LR2** 書かれた名前、`.ogg`、`.wav`。親フォルダでは書かれた名前、`.wav`、`.ogg`。末尾 3 文字を置き換えるので、3 文字の拡張子が付いている前提 [R]（[LR2f.cpp L14676-L14726][olr2-find-wav]）
- **beatoraja** 書かれた名前、次に `.wav`、`.flac`、`.ogg`、`.mp3`（書かれた拡張子は飛ばす）。デコードに失敗したら次へ進む [V]（[AudioDriver L207-L229][b-audio-ext]、[AbstractAudioDriver L691-L750][b-audio-load]）
- **Be-Music** Web プレイヤー：書かれた名前を最初に、次に `.opus`、`.ogg`、`.mp3`、`.wav`、`.m4a`（指定済みの拡張子は飛ばす）。見つからない場合やデコードに失敗した場合は次の候補を試す。譜面のフォルダの候補をすべて試してから親フォルダを探す（[`collection.ts`][bm-collection] `resolveChartAudioAsset`）。ローカルのファイルを読むターミナル版プレイヤーとオフラインレンダラー：書かれた名前を最初に、次に書かれた拡張子に応じて（例：`.wav` → `.mp3` → `.ogg` → `.opus` → `.m4a`）（[`sample-path.ts`][bm-sample-path]）

**`#BMP` の画像**

- **de jure** cmds：LR2 は同じ名前の PNG と JPG も探す（[`#BMPXX-IMAGE-FILE-FORMATS`][cmds-bmp-image]）
- **LR2** 書かれた名前、`.png`、`.jpg`、`.bmp`、次に親フォルダで同じ [R]（[LR2f.cpp L14607-L14673][olr2-find-image]）
- **beatoraja** 書かれた名前を最初には試さない：`.jpg`、`.jpeg`、`.gif`、`.bmp`、`.png`、`.tga` の順で最初に見つかったもの。見つからない画像は、まず動画として、次に画像として探す [V]（[BGAProcessor L135-L192][b-bga-lookup]）
- **Be-Music** LR2 と同じく書かれた名前を最初に試す。次に `.webp`、`.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`（書かれた拡張子は飛ばす）。この順番は Be-Music の方針で、容量を減らすために再エンコードしたパック向けに `.webp` を先にする。`#STAGEFILE`、`#BANNER`、`#BACKBMP` も同じ探し方。動画にはしない（[`collection.ts`][bm-collection] `resolveChartBGAAsset`）

**`#BMP` の動画**

- **de jure** cmds はプレイヤーごとに再生できるコンテナを挙げる（[`#BMPXX-VIDEO-FILE-DEFINING-TO-BMP`][cmds-video]）。差し替えについては記述なし
- **LR2** ほかの動画の拡張子は試さない。見つからない動画は `.png` / `.jpg` / `.bmp` として探す [R]（[LR2f.cpp L14607-L14673][olr2-find-image]）
- **beatoraja** 書かれた名前を最初には試さない：`.mp4`、`.m4v`、`.wmv`、`.webm`、`.mpg`、`.mpeg`、`.m1v`、`.m2v`、`.avi` の順で最初に見つかったもの。見つからない動画は画像にも置き換わる [V]（[BGAProcessor L135-L192][b-bga-lookup]、[VideoFormat L7-L13][b-video]）
- **Be-Music** 書かれた名前、次に `.mp4`、`.webm`、`.m4v`、`.mov`、`.mpg`、`.mpeg`、`.wmv`、`.avi`、`.mkv`（ブラウザがそのまま再生できるコンテナが先）。譜面のフォルダと親フォルダのどちらにも動画がなければ、同じ名前の静止画（`.webp`、`.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`）を探す（[`collection.ts`][bm-collection] `resolveChartBGAAsset`）

**`#STAGEFILE`、`#BANNER`、`#BACKBMP`**

- **de jure** 未定義

### 2.20 ナナシグルーヴ2 の `.n2s` コンテナ
