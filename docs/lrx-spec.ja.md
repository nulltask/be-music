# LRX 実装仕様

LRX は plugout4 -ARCADE EDITION- の譜面形式です。`.lrs` を譜面として開き、付属の XML ファイルと素材も同じフォルダー構成で読み込ませます。

## 対応状況

| 操作     | 対応                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| 読み込み | ブラウザー版と端末版で `.lrs` と付属ファイルを読み込みます。                          |
| 再生     | 共通のタイミング・ノート・音声モデルを使います。拡張 BGA はブラウザー版で合成します。 |
| JSON     | `lrx` 拡張を保持します。                                                              |
| 書き出し | BMS と bmson に対応しています。LRX の書き出しは未対応です。                           |

## ファイルと文字コード

| ファイル | 内容                                            |
| -------- | ----------------------------------------------- |
| `.lrs`   | `information`、`sound` の定義、`n` イベント     |
| `.lrh`   | 拡張子を除いた名前が同じヘッダー。省略可        |
| `.lrm`   | `image` / `movie` の定義と BGA イベント。省略可 |

BGA ファイルは、ヘッダーの `moviepath`、シーケンスの `moviepath`、`_movie.lrm` の順で決まります。BOM があれば UTF-16LE または UTF-16BE として読みます。BOM がなくても先頭の `<` のバイト列で UTF-16 を判別し、該当しなければ UTF-8 として読みます。LRX の読み込みに使うのは、文書順に並べた要素名と属性です。

付属ファイルを取得済みなら、`@be-music/chart-parser` の `parseLRXBytes` または `parseLRX` に渡します。Node の `parseChartFile` は付属ファイルをディスクから読み込みます。[パーサーの実装](../packages/chart-parser/src/core/lrx.ts)

## ヘッダーとタイミング

`.lrh` から曲名、副題、ジャンル、作者、画像、`lrslevel`、難易度を読みます。難易度の `category` 0〜4 は 1〜5 に対応します。`lanetype` と表示用 BPM もヘッダーから読みます。判定ランク（既定値は 2）と正の TOTAL は `.lrs` から読みます。そのほかのヘッダー項目は `BeMusicJSON.lrx` に残します。

`n` 要素の `c` はチャンネル、`s` は開始 tick、`e` は終了 tick、`p` は値です。1 拍は 480 tick です。

| チャンネル | 用途              |
| ---------- | ----------------- |
| 300        | 小節線            |
| 301        | BPM               |
| 302        | ミリ秒単位の STOP |
| 309        | プレイ終了        |

最初の BPM イベントを開始時のテンポに使います。イベントがなければ `startbpm`、なければ `basebpm` を使います。選ばれた値が無いか正でなければ、共通の既定 BPM を使います。STOP は同じ tick の BPM 変更を反映したテンポで換算します。小節線は記録された tick に置き、tick の長さには影響しません。

終了イベントがなければ、最後の音が鳴り始めてから 3 秒後にプレイを終了します。判定が残っているときは、Be-Music はその処理を待ちます。[終了処理の実装](../packages/chart-model/src/lrx-play-end.ts)

## レーンと音声

| `lanetype` | Be-Music のレイアウト  |
| ---------- | ---------------------- |
| 0 / 1      | 7 / 5 KEY              |
| 2 / 3      | 14 / 10 KEY            |
| 4          | 9 KEY（PMS-STD）       |
| 5 / 6      | 警告付きで 10 / 14 KEY |

有効な `lanetype` があれば、一部のレーンが空でも指定どおりに配置します。値が無いか未定義の場合は、使われているチャンネルから判断します。

- レーン上で `e > s` のイベントはチャージノートです。`dmg="0"` は自動で鳴り、そのレーンのキー音に切り替わることがあります。
- チェーンイベント（`cn="1"`）は通常、先行ノートを鳴らす入力に合わせて鳴ります。レーンの先頭にあるチェーンイベントは判定します。ノート数と空打鍵の扱いは[互換性ノート](./format-compat.ja.md#7-lrx)を参照してください。
- チャンネル 20〜199 は背景音です。そのうち 100〜199 で `dmg` が 0 でない音だけが BGM バスに入ります。ほかの音と不可視ノートはキー音バスに入ります。
- イベントごとに音量（`vol`）、パン（`pan`）、再生レート（`frq`）、フェード（`atk` / `rls`）、再生範囲（`ost` / `len`）を指定できます。同じサンプルの音は重ねて再生できます。

plugout の判定とゲージで遊ぶには、`plugout` ルールセットを選びます。[ルールセットの設計判断と根拠](./adr/0044-plugout-ruleset.ja.md)

## BGA と変換

チャンネル 200、201、202、299 は共通のベース、レイヤー、レイヤー 2、POOR 面に対応します。拡張 BGA ではレイヤー 203・204、切り抜き、変形、アニメーションのキーフレームを `lrx.bga` に保持します。ブラウザー版は 1280 × 720 の Canvas に合成し、ほかのホストは共通の BGA 面を使います。205〜298 は警告を出して省きます。

パーサーは LRX を共通のイベントに変換し、`sourceFormat: 'lrx'` を設定します。Be-Music JSON には LRX 固有のヘッダー値、ノート属性、拡張 BGA が残ります。BMS や bmson に書き出すと、チェーン再生やノート単位の音声設定など、LRX 固有の情報が失われる場合があります。[JSON 表現](./json-spec.ja.md)
